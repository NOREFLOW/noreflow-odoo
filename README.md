# Noreflow for Odoo 18.0

Connects Odoo to [Noreflow](https://noreflow.net): every sale, invoice and receipt issued in Noreflow is written to Odoo as a posted customer invoice with its payment, and Noreflow's assistant answers customers on WhatsApp in Arabic and English.

Install `noreflow_connector`, then open Invoicing > Configuration > Noreflow.
